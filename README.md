# PT Teguh Jaya Teknik 中文企业官网

## 使用方法
1. 解压 ZIP。
2. 使用 VS Code 打开项目文件夹。
3. 安装 VS Code 的 Live Server 插件。
4. 右键 `index.html` → `Open with Live Server`。

## 需要修改的内容
- `index.html`：公司名称、地址、邮箱、服务、案例等。
- `js/main.js`：把 `whatsappNumber` 修改为真实 WhatsApp 号码。
- `css/style.css`：可以更换首页和案例图片。
- `images/`：放入公司 Logo、工程照片和设备照片。

当前版本已经全部改为中文界面，并保留响应式手机端设计。
